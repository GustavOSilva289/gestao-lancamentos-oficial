## Publicação rápida
1. Crie um repositório no GitHub.
2. Envie TODOS estes arquivos para a raiz:
   - index.html
   - manifest.json
   - sw.js
   - logo.svg
3. No GitHub: Settings → Pages → Deploy from a branch → main → /(root).
4. Abra a URL HTTPS gerada no Chrome do celular.
5. Use "Instalar app" / "Adicionar à tela inicial".

O aplicativo abre em modo standalone e carrega o seu Apps Script dentro de uma tela de aplicativo.
